This folder contains screenshots and wireframes demonstrating key pages and functionality of the Meal Masters application.

1. Home Page

Shows the main recipe feed tailored to the user’s dietary preferences. Users can browse, save, or open recipes.

2. Recipe Screen

Displays full recipe information: ingredients, instructions, image, and an option to save or add to meal planner.

3. Meal Planner Page

Allows users to select a day + meal type and add recipes to their weekly plan.

4. My Meal Plan Page

Displays a weekly overview of chosen meals (breakfast/lunch/dinner/snacks) organised by day.
Users can click recipes to view details.

5. Profile Setup Page

User can set dietary preferences including allergies, intolerances, and diet type.
These settings influence recipe suggestions.

6. Settings Page

Contains theme toggle (light/dark), screen size optimization and logout control.

7. Wireframes

Initial design sketches for core pages.
